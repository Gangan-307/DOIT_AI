# DOIT AI C5 KIT LCD

本目录包含 DOIT AI C5 LCD 板级适配代码，负责 C5 的供电保持、按键、LCD、RGB 指示灯、网络切换和电量监测。

## 相关文件

| 文件 | 作用 |
| --- | --- |
| `doit-ai-c5-kit-lcd.cc` | C5 板级初始化、BOOT 按键、状态栏位置和电量接口 |
| `config.h` | C5 的 GPIO、LCD 和电池分压参数 |
| `esp_lcd_panel_st7789_fix.c` | C5 ST7789 LCD 的初始化与驱动补丁 |

## 启动流程

设备启动时，父类根据已保存的配置建立 4G 或 Wi-Fi 网络。随后 C5 板级代码执行以下初始化：

1. 拉高 GPIO27，保持系统供电。
2. 创建 RGB 指示灯初始化任务。
3. 注册 BOOT 按键的单击、双击和多击事件。
4. 初始化 LCD SPI 总线、ST7789 屏幕、LVGL 和背光。
5. 初始化 GPIO5 电池 ADC 监测器。
6. 恢复保存的背光亮度。
7. 注册 VB6824 唤醒词和“开始配网”语音命令。

## BOOT 按键

- 单击：打印当前网络与设备状态。Wi-Fi 未连接且设备仍处于启动状态时，清除 Wi-Fi 配置；设备未处于监听状态时，触发语音唤醒。
- 双击：仅限开机后 30 秒内。4G 模式切换到 Wi-Fi；Wi-Fi 配网模式切换到 4G。切换后设备重启。
- 三击及以上：仅在 Wi-Fi 已连接时清除 Wi-Fi 配置，重启后重新进入配网模式。
- 开机超过 30 秒后的双击：启用 VB6824 OTA 支持且 Wi-Fi 已连接时，按 OTA 逻辑处理。
- 接电池情况下，长按开关机。

## 状态栏

- 时间由公共显示模块显示在顶部中间区域。
- 网络图标固定在顶部左侧。
- 电池图标固定在顶部右侧。
- 网络状态每 10 秒更新一次，根据当前 Wi-Fi 或 4G 状态切换图标。

## 电量与低电量弹窗

- 检测为充电状态时，状态栏显示闪电电池图标。
- 未充电时，状态栏按 `0%~19%`、`20%~39%`、`40%~59%`、`60%~79%`、`80%~100%` 显示空电池至满电图标。
- 电量处于 `0%~19%` 且处于放电状态时，显示“电量低，请充电”弹窗并播放提示音。
- 开始充电或电量高于低电量范围后，弹窗自动隐藏。

## Wi-Fi 配网超时

若设备在 Wi-Fi 配网时无法连接路由器，或网页在设备实际连上路由器前就显示失败，可将配网等待时间从 10 秒调整为 30 秒：

```cpp
// managed_components/78__esp-wifi-connect/wifi_configuration_ap.cc
pdMS_TO_TICKS(10000)
```

修改为：

```cpp
pdMS_TO_TICKS(30000)
```

修改后重新编译和烧录固件。调试时可关注以下日志：

```text
Connecting to WiFi
Connected to WiFi
Got IP
```
